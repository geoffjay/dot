* **Implementation (M0–M6)**: Built the dot workspace per the plan — `crates/dot-core` (config/facts/module/render/plan/diff/state/backup) and `crates/dot` (CLI), 13 embedded modules (example + zsh, bash, git, tmux, starship, lsd, gh, ghostty, kitty, htop, brew) migrated from cfg, tower-derived packaging (release workflow, AUR/Homebrew generators, cargo-make tasks), and tower-derived release tooling. All commands verified by unit tests (29 core + 5 CLI), integration tests, and `scripts/e2e.sh`. Recorded [concepts/commands.md](concepts/commands.md), [decisions/embedded-modules.md](decisions/embedded-modules.md), and [decisions/minijinja.md](decisions/minijinja.md) along the way.
* **zsh ingestion**: Ingested this host's zsh configuration into the zsh module — 34 files: `.zshrc`, `.zprofile`, `.zshenv`, `.zshenv.d/00-keep`, all 21 `.zshrc.d` fragments, 7 `.zsh/util` scripts, and 2 plugins. Method: copy verbatim, template only machine-bound values (`gcloud-root`, `docker-bin`, `java-home`, `hist-size`, `bat-theme` as module defaults), add `has()` guards only where live content evals unconditionally (starship/yarn/git-spice fragments; docker/brew in zprofile). Verified byte-exact via `cargo run -p dot-core --example verify_zsh` (34/34 identical after fixes). Fixed two real bugs the verification caught: minijinja dropped trailing newlines (now `set_keep_trailing_newline(true)` + regression test), and initial `# Managed by dot` headers broke byte-exactness (removed — the manifest, not comment headers, defines ownership). Pattern recorded in [concepts/ingestion.md](concepts/ingestion.md).
